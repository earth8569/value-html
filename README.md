# value-html

An Obsidian-style graph notebook that stores every note as a real, human-readable `.html` file.

- **Graph view** with force layout, filters, local graph, tag and ghost nodes
- **Color groups** (query + color, e.g. `tag:#idea`, `path:Projects`) with optional cluster separation
- **HTML storage**: notes are standalone `.html` files with relative links, readable in any browser
- `[[wikilinks]]` with autocomplete, backlinks, rename-with-link-updates, autosave

## Run

Open `index.html` in Chrome or Edge (or serve the folder, e.g. `python -m http.server`), then choose
**Open a vault folder**, or **Try the demo vault** to explore with sample notes.

No build step, no dependencies.
